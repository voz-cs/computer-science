# Lecture 1: Introduction to Computation

## 📌 Các khái niệm cốt lõi

1.  **Computation (Tính toán):** Không chỉ là con số, mà là việc lưu trữ và thực thi các tập lệnh để biến đổi dữ liệu.
2.  **Knowledge (Kiến thức):**
    - **Declarative:** "Sự thật" (Căn bậc hai của x là y sao cho y\*y=x).
    - **Imperative:** "Cách làm/Thuật toán" (Các bước cụ thể để tìm y).
3.  **Computers:**
    - **Fixed-program:** Máy tính 1 chức năng (Casio).
    - **Stored-program:** Kiến trúc Von Neumann. Dữ liệu và Lệnh lưu chung. Cho phép máy tính trở nên đa năng.

## Python móng đơn

- **Objects:** Mọi thứ trong Python là một Object.
- **Scalar Objects:** `int`, `float`, `bool`, `None`.
- **Expressions:** Kết hợp các Objects và Operators để tạo ra giá trị mới.
